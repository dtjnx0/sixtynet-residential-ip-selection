## IP 干不干净，用三个指标自己验

买住宅 IP 最怕买到“机房 IP 套壳”。下面三个检查方法不需要技术背景，拿到机器后十分钟能跑完。

**一、查 ASN 与 usage type。**把 IP 丢进 IPinfo、ipapi 这类数据库，看 ASN 归属是运营商还是数据中心，usage type 写的是 ISP/Cable/DSL 还是 Hosting。住宅宽带 IP 的 ASN 应该指向 AT&T、Frontier、Cox、Astound 这类运营商。

**二、跑流媒体解锁脚本。**常用的是 `bash <(curl -Ls IP.Check.Place)`，一次把 Netflix、Disney+、YouTube、ChatGPT、Gemini、Claude、TikTok 区域全测出来。

**三、手测三个动作。**Google 搜一次看有没有验证码；TikTok 登录看区域是不是 US；注册一个不常用的服务看会不会立刻要手机号。

什么叫“干净”，用第三方对 Sixtynet 的实测结果举例更直观。2026 年 2 月有人测过 Sixtynet 的 Wave（Astound Broadband）家宽线，IP 段 104.202.\*.\*，结果是：Netflix、Disney+、YouTube Premium、Hulu、HBO Max、Amazon Prime Video 之外的北美流媒体基本全绿，ChatGPT、Gemini、Claude 全部 Yes，TikTok 区域显示【US】，Google 搜索无验证码。同时有两处不完美：Spotify 注册是 No，Bing 区域标了 US (Risky)，Amazon Prime Video 报页面错误。

这种“大面积通过、个别项掉队”就是真实住宅 IP 的典型面貌，比全绿的截图可信。要注意，这次测的是 Wave 线，不是本文的尔湾 IRVINE-PRO 线，Sixtynet 尔湾机型的公开实测数据目前没有，是否同样的解锁表现需要你自己验。

更早的一份第三方测评（2025 年 10 月）测的是 Sixtynet 的 Cox Communications 双 ISP 住宅 IP，结论是 IPv4 为美国原生、双 ISP 住宅属性、解锁效果好，同时确认官方屏蔽 PING、屏蔽 80 和 443 端口，三网去程电信走 CN2、联通移动直连洛杉矶，回程电信移动走 CN2、联通走 AS9929。

## 国内连得稳不稳，要不要中转

这个问题得分开看两条产品线。

IRVINE-PRO 页面把“AS9929 Optimize for China”写进了配置项，意思是中国方向走了联通精品线路。这类线路的典型表现是国内直连延迟可控、晚高峰不至于断崖式掉速，日常远程桌面、后台操作不需要额外搭中转。

Residential 系列页面没有这条。按同类产品的普遍情况，纯美国住宅宽带落地，国内直连延迟通常在 180–220ms 这个区间（第三方测评别家尔湾机型时记录的数字），能用，但 SSH 敲命令和远程桌面会有点黏。想要顺滑，就得加一台前置中转。

中转的做法叫链式代理：前置节点负责回国线路，落地节点负责出口 IP，客户端配置里让落地节点挂在前置节点后面。Clash Verge（Mihomo 内核）的写法是在落地节点的配置里加一行 `dialer-proxy: "前置节点名"`；Shadowrocket 里选好落地节点后再指定“代理通过”走线路节点，配合规则组让 AI 类、账号类流量自动走家宽。

一个容易踩的坑：落地协议别用老式 SS 直连，容易被墙。前置用 vless + reality 更稳，落地用 SS2022，两者串起来。

延迟数字的口径要看清：中转后测出来的 5–25ms 是“到洛杉矶”的延迟，不是国内到洛杉矶；国内直连的 180–220ms 才是你实际感受到的那个数。别把两个数放一起比。
